# User Stories — SIDEQUEST

Format: `As a [role], I want to [action], so that [benefit].` Tagged MoSCoW per
[PRD.md](PRD.md) prioritization, with the shipping phase from
[ROADMAP.md](ROADMAP.md) noted. **Must** = Phase 2 (MVP) unless stated.

## Onboarding & Identity

- As a new user, I want to pick interests, group-size preference, and vibe in
  under a minute, so I get relevant quests immediately. **Must**
- As a user, I want a username and optional real name, so I control how
  exposed I am. **Must**
- As a user, I want to set my profile to public or friends-only, so I control
  discoverability. **Must**
- As a user, I want location permission requested with a clear explanation of
  why, so I'm not asked to trust a black box. **Must**

## Discovery

- As a user, I want to see quests starting soon near me, so I can act
  spontaneously. **Must**
- As a user, I want to filter by distance, budget, category, group size,
  difficulty, and indoor/outdoor, so results stay relevant. **Must**
- As a user, I want to see friend activity in discovery, so I can join what
  people I know are doing. **Should — Phase 3/4**
- As a user, I want AI-recommended quests based on my history, so discovery
  gets better the more I use the app. **Should — Phase 3**

## Quest Creation & Participation

- As a user, I want to create a quest with time, budget, category, and
  capacity, so others can join something concrete. **Must**
- As a user, I want to set a quest's visibility (public / friends-only /
  private invite), so I control who can find it. **Must**
- As a user, I want to join a quest and see who else is in, so I know what
  I'm walking into before committing. **Must**
- As a user, I want to leave a quest before it starts, so plans that don't
  work out don't strand me. **Must**
- As a user, I want to describe my situation in free text and get an AI-
  generated quest draft I can edit before publishing, so I don't have to plan
  from scratch. **Should — Phase 3**

## Quest Rooms & Completion

- As a participant, I want a temporary group chat, participant list, meeting
  point, and objective checklist per quest, so coordination happens in one
  place. **Must**
- As a participant, I want to check in when I arrive, so the group knows I've
  shown up without exposing my live location beforehand. **Must**
- As a participant, I want to mark objectives complete (manually, or via
  photo/QR where required), so the quest resolves and everyone gets XP.
  **Must**
- As a participant, I want the room to archive into my quest history after
  completion, so I can look back on it later. **Must**
- As a user, I want AI to verify a photo objective (e.g. "find a red vending
  machine"), so completion isn't purely on the honor system. **Future — Phase 8**

## Social

- As a user, I want to send and accept friend requests independent of quest
  participation, so my social graph isn't quest-bound. **Must**
- As a user, I want to block or report a user, so I can stop unwanted contact.
  **Must**
- As a user, I want to add quest participants as friends after completing a
  quest together, so good connections aren't one-off. **Must**
- As a user, I want to see a compatibility score and its breakdown before
  joining, so I understand why a quest was suggested to me. **Should — Phase 3**

## Gamification

- As a user, I want XP and levels for completed quests, so effort is
  recognized. **Should — Phase 4**
- As a user, I want achievements for specific behaviors (first quest, night
  owl, photographer), so progress feels varied, not just a single number.
  **Should — Phase 4**
- As a user, I want my quest history and stats visible on my profile, so I
  have a record of what I've actually done. **Should — Phase 4**

## Notifications

- As a user, I want quest invitations, friend requests, and start-time
  reminders as notifications, so I don't miss things I opted into. **Must**
  (basic set); richer preferences **Should — Phase 3/4**
- As a user, I want to control notification categories individually, so the
  app doesn't over-notify me. **Must**

## Business *(Phase 5)*

- As a business, I want to create a sponsored quest with a discount reward, so
  I get measurable foot traffic. **Could**
- As a business, I want campaign analytics (views, joins, completions,
  redemptions), so I can judge ROI. **Could**
- As a business, I want a verification process before my quests go live, so
  the platform stays trustworthy for users. **Could**

## Creator Marketplace *(Phase 6)*

- As a creator, I want to publish a paid quest template with a configurable
  revenue split, so I can monetize local knowledge repeatably. **Could**
- As a creator, I want purchase and completion analytics, so I know what's
  working. **Could**

## Booking *(Phase 7)*

- As a user, I want to see availability and book an activity (e.g. a bowling
  lane) directly tied to a quest, so I don't have to leave the app to
  confirm logistics. **Could**

## Admin / Trust & Safety

- As an admin, I want a report queue with full target context, so I can act
  on abuse quickly. **Must**
- As an admin, I want to suspend a user or delist a quest, so harmful content
  stops spreading without waiting on a full investigation. **Must**
- As an admin, I want to verify business accounts before they can sponsor
  quests, so sponsorship isn't a spam vector. **Could — Phase 5**
- As an admin, I want platform health and moderation dashboards, so I can
  spot systemic issues, not just individual reports. **Should — Phase 4/5**
